# App CLB Eleven Park

Giao diện web app cho thành viên CLB Eleven Park: vote điểm danh, check-in GPS tại sân, Sao đỏ, ví quỹ, hồ sơ.

- Link app: https://thinhdaohop.github.io/elp-app/
- Dữ liệu và xử lý: Google Apps Script + Google Sheets (file quỹ ELP 2026).
- Cấu hình đường dẫn API trong `config.js`.
